Tapziq Browser Keyboard

An installable PWA with an on-page virtual keyboard, local Gemma 4 proofreading, and optional autocorrect.

A PWA, not a system keyboard

The virtual keyboard edits only the text area inside the Tapziq page. A web app cannot register itself as Android's InputMethodService, replace the selected Android keyboard, or read and edit fields in other apps, sites, or browser tabs. The native Android Tapziq keyboard is a separate application and architecture.

Exact boundary: this browser edition does not call Gemini Nano, Android AICore, ML Kit, or a remote inference API. It downloads the web-specific Gemma 4 E2B-it artifact into storage managed by this browser for the Tapziq origin and performs inference in a dedicated WebGPU worker.

What “browser-managed” means

ComponentLocation and lifetime
App and runtime Served by the Tapziq origin and cached there by the service worker. LiteRT-LM runtime files are self-hosted, not loaded from a CDN during inference.
Gemma model Downloaded only after confirmation, written to the browser origin's OPFS, and accepted only after its size and SHA-256 match the pinned artifact.
Editor and suggestion Kept in volatile page and worker memory. Tapziq application code does not persist them in OPFS, Cache Storage, local storage, cookies, or a server.
Inference Runs locally in a dedicated browser worker with WebGPU. Tapziq has no inference backend.

Browser-managed is a technical storage and execution boundary. It is not a claim that the browser is an impenetrable vault or that ownership of third-party software or model weights changes. The browser, operating system, sufficiently privileged extensions or administrators, developer tools, malware, and anyone controlling the profile or device may be able to inspect or delete site data.

Requirements

  • A secure HTTPS origin or localhost; file:// is unsupported.
  • A current browser with WebGPU, a GPU adapter, OPFS, and Web Locks. LiteRT-LM's web API is an early preview.
  • 2,008,432,640 bytes for the model plus 512 MiB of free browser quota during setup.
  • A suitable GPU. A published M4 Max WebGPU benchmark reports roughly 1.8 GB of GPU memory; actual devices differ.
  • Browser permission to retain enough site data. Persistent storage is requested but not guaranteed.

Use and user control

  1. While online, choose Download verified model and confirm the displayed remaining size.
  2. Leave the page open for the download. A paused partial file can be resumed. Tapziq verifies every byte before enabling the model.
  3. Type with the on-page keys or paste into the editor.
  4. Optional: turn on Auto-correct with Gemma 4. It is off by default and checks recent text only after a virtual space, completion punctuation, or Enter. Automatic changes require an exact unchanged snapshot and offer one-step Undo.
  5. For manual proofreading, select at most 500 UTF-16 code units, or use the whole editor when it is at most 500, then choose Proofread with browser Gemma 4.
  6. Review the manual preview. Only Apply changes text; Dismiss and Cancel do not. Manual and automatic stale results are rejected.

Once the app shell, runtime, and verified model have loaded, proofreading can run offline. An app update, missing cache entry, removed model, cleared site data, or browser eviction requires network access again.

Remove browser model deletes the complete or partial model and its verification metadata. Use the browser's site-data controls to delete the app cache and all other origin data. Uninstalling a PWA alone does not clear site storage in every browser.
